# listening-diff

Web app para treinar listening em inglês. Você escreve o que ouviu, cola o texto original e o app mostra exatamente onde você errou.

> Projeto em desenvolvimento. A lista de funcionalidades mais abaixo mostra o que já está pronto e o que ainda falta.

## Por que eu fiz isso

Estou estudando inglês e o meu ponto mais fraco é o listening. Uma das formas de treinar é transcrever o que escuto e depois conferir com o texto original, mas conferir na mão é chato e, pior, eu acabava não percebendo meus erros mais comuns.

Então decidi automatizar essa parte. O app compara as duas versões palavra por palavra e mostra o que acertei, o que esqueci, o que inventei e o que troquei por outra coisa.

## Como funciona

1. Você ouve um trecho de áudio em inglês.
2. Escreve o que entendeu no primeiro campo.
3. Cola o texto original no segundo campo.
4. Clica em comparar.
5. O app mostra o texto com cores indicando cada tipo de erro e a porcentagem de acerto.
